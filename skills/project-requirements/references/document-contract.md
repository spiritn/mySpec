# 方向审查文档约定 v3

## 一份主文档

用户日常只需打开 `整体思路.md`。项目根目录按业务目标确定，可覆盖多个代码仓库；默认输出 `<项目根目录>/docs/方向审查者/`，已有指定位置沿用。

```text
方向审查者/
├── 整体思路.md
├── 变更记录.md
└── 调研/          有专项资料时才创建
```

`整体思路.md` 集中放目标背景、术语、竞品／市场／方案调研、整体方案与进度、待定与验证、决策表。普通问题在原章节更新，不新建项目总览、项目依据、工作包、验证清单、决策总表或单项 ADR。用户明确另有要求时按用户要求。

`变更记录.md` 按日期追加有意义的变化，不按天建文件，不记工具流水账。`调研/` 只保存确需展开的竞品、技术、可行性或验证方法依据；同主题优先更新。执行实验的原始配置、数据和结果留在实验工程并链接，不复制到审查目录。

只有主会话统一写入，评审子 Agent 返回判断和建议。来源只需足以追溯：文件位置、日期/版本、原话或可用聊天引用；不能编造聊天 ID。已有项目来源原位引用。

## 主文档写法

- 第一节固定为 `## 当前判断`，总计≤300个非空白可见字符，首段≤100且计入300。说清判断、最强依据、关键未知、下一步。后续各节只展开必要内容，不把摘要重复一遍。
- 目标背景写清用户要什么、为什么做、已确认范围及约束。允许需求模糊，把未知限定在具体问题上，不把已确认目标重新写成待定。
- 术语只解释容易误读且与项目有关的词；沿用已确认的含义。一个词一个含义，未定时直接写未定，不另造听起来专业的词。
- 调研章节按项目选择“竞品调研”“市场分析”或“方案调研”。正文面向人介绍：谁在做、怎么做、亮点和成果是什么，再说明重要未知。竞品按厂家／产品用短小节说明推出时间、方案与关键技术、公开成果及条件、与本项目相关的未公开细节；不强制宽表，不以“当前依据／主要缺口”代替方案介绍。市场分析看客户需求和已有供给，方案调研看可选办法；字段随问题调整。
- 发布时间有来源才写，文章发布日期不冒充产品首发；未确认可写最早查到的公开介绍日期。厂商宣称的结果保留对象、基线和条件，不转述成独立实测。标准、软件库、硬件芯片与模型名称分别说明；公开H.265不能据此猜成x265或NVENC。长资料链接到已有来源或调研文档。
- 方案与进度按可验证的问题拆解，说明每步作用、输入/依赖、结果/通过条件及实际进展；表格可合并相关字段。近期具体，远期允许待定；图最多7节点，用短句表示实际依赖，假设用虚线注明。
- 待定与验证保留影响决定的问题、最小查明办法和当前状态；不为每个问题新建文件，不要求所有未知都消失才能准备下一步。
- 决策表嵌在本文，细则见下文。章节通常先用≤100字说明核心意思，再放必要短表或列表；没有内容的可选章节可省略，不能用占位文档凑结构。

整份主文档没有300字硬上限，但要删除重复、减少宽表和无关细节。300字同样适用于默认聊天审阅及子 Agent 的判断；主会话明确索取的来源明细可另附。不得为控字继续拆管理文件或把正文塞进图。

## 决策只有一张表

| 决策点 | 描述 | 结论状态 | 论据 | 时间 |
| --- | --- | --- | --- | --- |
| 一个需要决定的问题，可带已有编号 | 选项和当前建议，各用短句 | 待决策；或已决策：实际决定；或已替代：新条目 | 当时背景和依据；已决策附可核验的人工确认出处 | 确认日期或更新日期，标明类型 |

每个单元格只写必要短句；长论据链接已有资料。保留旧编号便于追溯，新记录不强制编号。AI 可以提出选项、建议和论据，只有用户明确人工确认或已有可核验人工确认才标已决策。没有确认来源、日期或门槛时如实写未确认，不猜。

同一待决策问题更新原行。质疑已决策事项时保留原决定及当时依据，增加关联的待决策行；新决定经人工确认后才把旧行标已替代，变化写入日志。不另建 ADR 文件。人工明确否决或暂缓也可作为已决策结论。

决策、进展、证据分别表达：待决策不等于未开始，已完成不等于已验证；两人一致不等于人工批准。进展可用未开始/进行中/暂缓/已完成/未核实，证据可用未验证/验证中/当前范围支持或不支持/冲突。先试某技术不等于选定主路线。

## 字数检查和旧目录整理

标题、表格文字、数字、标点、代码、链接标签和图注计入可见字符，格式符号和链接地址不计；不得藏入元数据或 HTML 规避。检查器只支持项目使用的 Markdown 和简单 Mermaid，不是通用渲染器，也不证明推理正确。

主文档运行 `scripts/check_document.py /absolute/path/整体思路.md --overview`；独立短答用 `--brief`；专项资料不加这两个参数。摘要必须在正文开头的 `## 当前判断`，到下一一级或二级标题结束，不能只圈出一段很短的文字逃避检查。

合并旧目录先留可恢复备份，再提炼有效内容和全部已有决定，修正链接后移除已合并文件。备份放工作区或独立交付包，不留在日常审阅目录制造第二套入口。原始资料、确认原话和历史决定需可追溯；无需把旧全文复制进新的主文档。来源快照保持原样，在变更记录说明旧路径的新位置。
